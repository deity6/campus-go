校园网自动认证  v4.3.1
========================

【适用范围】

本程序按 WZUT 的校园网认证流程实现与实测，属于 WZUT 专用适配。
其他学校或其他网关变体不保证直接可用，可能需要修改参数或认证流程。

【怎么用】

1. 双击「校园网认证.exe」。
2. 第一次打开，先在左侧「账号」页填好网关、账号、密码，点保存。
   网关填学校认证页地址栏里的那个 IP；有线网和校园 Wi-Fi 都可用。
   密码保存后仍会显示在框里，点右侧的眼睛图标可以看明文，
   也可以随时改。
3. 之后就不必管了。程序常驻托盘，掉线会自动重连。

关掉窗口不会退出程序 —— 它只是收进托盘继续跑。
要彻底退出，右键托盘图标 →「退出」。


【托盘】

单击托盘图标  → 立刻打开主界面
右键托盘图标  → 菜单

图标颜色代表状态：
  绿色   已连接
  红色   未连接
  琥珀   正在检测 / 正在认证
  灰色   时段外，暂不自动重连


【第一次打开】

  会有一段引导，指着界面告诉你哪个按钮干什么用。
  没登录时引导里的称呼是演示数据；播放结束会自动散掉。
  看完（或者点「跳过」）之后，设置里的「使用引导」会自动打勾。
  以后想再看一遍，把那个勾去掉，下次启动就会重新播放。

【概览能看到什么】

  连上之后会显示「晚上好，X 同学」这样的问候（姓名只保留姓，不显示全名）。
  称呼可以点击循环：X 同学 → 同学 → 朋友 → X 同学。
  下方「本次连接」列出校园网 IP、MAC、上线时间、已用时长、已用流量。
  IP 和 MAC 默认显示为「已加敏」盾牌胶囊；点胶囊或旁边的小盾牌可临时查看。

【隐私脱敏】

  设置页提供三个开关：
    全局加敏       一键把姓名和网络信息都切到脱敏状态
    姓名加敏       隐藏姓氏，或进一步替换学生身份；也可点击首页称呼循环切换
    网络信息加敏   IP、MAC、网关默认打码
  这些选择会保存在本机 config.json，重启后仍然记住。

【四个主要功能】

  立即认证   立刻向网关发起登录
  断开认证   断开当前校园网认证（需要二次确认，断开后要重新认证才能上网）
  检查连接   立即检测一次校园网当前是否通
  自动重连   掉线后自动恢复，见下面的时段设置

断开认证会先后尝试网关的两个注销接口；如果都没生效（学校开启了
无感知认证时会出现这种情况），会提示并可以直接打开自助服务页面
手动注销。

【状态文字怎么看】

  网络正常       可以正常上网
  需要认证       连上了校园网但还没认证，点「立即认证」
  未连接校园网   没找到能访问认证网关的有线或 Wi-Fi 连接
  网络不通       外网和网关都连不上

  判断"通不通"用了三层：先 ping，再看能不能跟网站完成 HTTPS 握手，
  最后才用 Windows 自己的连通性判据。所以"禁 ping 但网页能开"的网络
  也不会被误判成断网。

【关于网络检测】

检测绑定「能到达认证网关的源 IP」，不假设必须插网线。
有线网和无密码校园 Wi-Fi（连接后打开网页会跳认证的那种）都支持。
如果电脑同时有别的网络，也不会把别的网络误判成校园网已认证。

【自动认证时段】

「自动认证时段」页里可以设定每天哪几个小时自动重连。
时段外只检测、不自动重连，但随时可以手动点「立即认证」。
可以直接选择开始 / 结束时间，也可以拖动时间轴调整。

「重点时段」是给已知会断网的时间段用的（比如宿舍晚上 4 点断网）：
这期间检测更密、判定更激进，断网后几秒内就能连回来。
支持跨零点，最长 1 小时。

改完点保存即刻生效，不用重启。

平时网络正常时是 3 分钟检测一次，不占资源也不打扰网关；
一旦发现异常会自动加密到 15 秒，网络恢复后再慢慢退回 3 分钟。


【文件说明】

  校园网认证.exe   程序本体，单文件，不需要安装运行时
  config.json      你的账号与设置（首次运行自动生成，含明文密码，别外传）
  autologin.log    运行日志，排查问题时看这个


【常见问题】

问：双击没反应？
答：可能已经在运行了（托盘里找找）。程序只允许开一个实例，
    再双击会把已有窗口叫出来。

问：不插网线，连校园 Wi-Fi 能用吗？
答：可以。先在 Windows 里连上学校 Wi-Fi，再打开本程序；
    网关 IP 仍填认证页地址栏里的那个 IP。

问：其他学校能用吗？
答：不一定。当前按 WZUT 认证流程实现与实测；其他学校的网关、
    参数或门户流程可能不同，需要自行适配或确认后再用。

问：界面是白屏？
答：缺 WebView2 运行时。Windows 11 和较新的 Win10 都自带；
    没有的话装一次「Microsoft Edge WebView2 Runtime」就好。
    认证功能不受影响，程序仍在托盘正常工作。

问：换台电脑要重新填账号吗？
答：便携版，整个文件夹拷过去即可，config.json 里就带着设置。

问：怎么开机自动启动？
答：界面「设置」页打开开关，或右键托盘 →「开机自启」。

问：程序会不会把密码传到别处？
答：不会。密码只存在本地 config.json，登录请求只发往校园网网关。

问：截图发给别人会泄露信息吗？
答：默认会隐藏姓氏，IP、MAC 和网关也会显示为「已加敏」。
    如需临时查看，点「已加敏」胶囊或旁边的小盾牌；看完再点一次即可恢复。


【卸载】

删除整个文件夹即可。如果开过开机自启，先在设置里关掉。
（WebView2 会在这个位置留一份缓存，可一并删除：
  %LOCALAPPDATA%\CampusAutoLogin）
